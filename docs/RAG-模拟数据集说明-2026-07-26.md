# 智慧食堂 RAG 模拟数据集说明

## 1. 用途与边界

本数据集用于真实学校数据到位前的本地检索、安全、租户隔离、性能和故障降级验证。它不是学校真实菜单，不得用于生产推荐、营养结论、配方结论或过敏原安全承诺。

- 数据版本：`simulation-2026.07.1`
- 固定随机种子：`0x6d2b79f5`
- 本地产物目录：`.rag-simulations/v1`
- 本地数据库：`.rag-simulations/v1/simulation.sqlite`
- Git 状态：生成目录已由 `.gitignore` 排除
- 生产保护：所有记录包含 `synthetic=true`，manifest 包含 `productionLoadForbidden=true`

## 2. 数据规模

| 数据 | 数量 |
| --- | ---: |
| 虚拟高校 | 10 |
| 食堂 | 50 |
| 档口 | 500 |
| 菜品 | 5,000 |
| 30 天、三餐菜单 | 4,500 |
| 菜单供应记录 | 90,000 |
| 全局规范概念 | 500 |
| 全局健康知识 | 14 |
| 单轮评测查询 | 2,000 |
| 多轮对话 | 300 组 |
| 故障注入 | 100 组 |

十所高校分别模拟北方综合、南方综合、民族、体育、医科、理工、沿海、内陆、超大型和多校区类型。每校固定 5 个食堂、50 个档口、500 道菜，以确保租户规模一致并便于横向比较。

## 3. 覆盖的数据事实

每道模拟菜品包含：

- 租户、食堂、档口、菜名、价格和上下架状态。
- 主配料、调味料、添加物、菜系、口味、标签和餐次。
- 热量、蛋白质、脂肪、碳水、纤维、钠和糖。
- 清真、饮食模式、辣度及其事实状态。
- 结构化过敏原声明、来源、核验时间、失效时间和数据版本。
- 评分、评价数、销量、图片状态和本地模拟标志。

过敏原状态只允许：

- `confirmed_absent`
- `confirmed_present`
- `unknown`
- `cross_contact_possible`

营养、配方、清真、饮食模式和辣度事实状态只允许 `unknown / estimated / verified`。

## 4. 动态菜单与脏数据

30 天菜单按早餐、午餐、晚餐生成，并包含每日价格变化、供应上限、已售数量、售罄和归档菜单。当前固定注入：

| 脏数据 | 比例 | 系统预期行为 |
| --- | ---: | --- |
| 过敏原未知 | 15% | 允许查看，必须返回 `ALLERGEN_UNVERIFIED` |
| 营养不完整 | 10% | 不得据此宣称低脂、低糖或低钠 |
| 菜单过期/延迟 | 5% | 不得宣称当前可售或虚构库存 |

另外覆盖同名变体、简称、错别字、方言式查询、图片缺失、跨校同类数据及模型/数据库/弱网故障契约。

## 5. 生成文件

| 文件 | 内容 |
| --- | --- |
| `manifest.json` | 版本、数量、随机种子和生产禁用标记 |
| `simulation.sqlite` | 10 校完整实验库和本地向量索引 |
| `evaluation-queries.jsonl` | 2,000 条冻结单轮评测，不写入向量库 |
| `multi-turn-conversations.jsonl` | 300 组 3–6 轮安全约束对话 |
| `fault-injections.jsonl` | 100 组故障与预期降级行为 |

## 6. 可重复执行

```powershell
npm.cmd run generate:rag-simulation
npm.cmd run eval:rag-simulation
npm.cmd run eval:rag-simulation -- --with-vectors --vector-sample=100
```

带向量评测要求本机 Ollama 提供 `qwen3-embedding:0.6b`，OpenAI 兼容地址为 `http://127.0.0.1:11434/v1/embeddings`，实际向量维度为 1024。最终本地索引包含 5,000 个租户菜品文档、500 个 `__global__` 校园饮食概念和 14 个 `__global__` 健康知识文档，三类文档的模型和维度已经逐项核验。

## 7. 已知限制

- 菜品由有限原型组合生成，名称和问法的重复度高于真实学校。
- 菜谱、营养和标签是模拟值，不能作为食品事实。
- 当前策略比较集对精确菜名和同义表达偏友好，不能替代真实搜索日志。
- 30 天变化已覆盖价格、供应、售罄和过期，但节假日、天气、排队数据仍是评测语义，不是完整时序传感数据。
- 真实阈值校准仍需至少一家学校的脱敏菜单、配方、过敏原和供应数据。
