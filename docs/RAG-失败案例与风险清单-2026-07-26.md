# 智慧食堂 RAG 失败案例与风险清单

## 1. 当前自动评测失败

本轮 RAG 模拟评测的解析、安全、租户、引用、多轮和故障断言均无失败。概念向量评测为 285/289，存在 4 条 Top-3 未命中；总命中率 98.62%，达到 95% 门槛，但失败样例必须继续保留。该结果不等于系统已经通过真实学校验收。

## 3. 已修复的代表性解析错误

- “我对花生过敏”只提取 `花生`，不再把整句冗余词当过敏原。
- “黑椒牛肉意面”中的“黑椒”不再被误解析成独立硬口味筛选。
- “蛋白质至少 25 克”不再把 `25` 误识别为预算。
- “不要售罄”转换为 `orderableOnly`，不再把“售罄”当忌口食材。
- “微辣”优先于通用“辣”匹配，不再被判成中高辣。
- “能吃鸡蛋，但不要花生”保留允许项与禁止项的作用范围。
- 多轮用户可以撤销普通口味偏好，但不能无提示撤销已声明过敏限制。

## 4. 必须拒绝或返回空结果的情况

- 用户要求跨租户读取其他学校隐藏菜品或库存。
- 用户要求虚构数据库不存在的菜品、价格、营养、位置或供应。
- 已确认含有目标过敏原或存在交叉接触风险。
- 纯素等硬饮食模式与指定肉类发生冲突且未确认修改。
- 预算与指定菜品价格冲突且没有合规候选。
- 关键证据缺失、引用 ID 不合法或模型输出包含无证据数值。
