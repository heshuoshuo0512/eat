## 4. 四种检索策略

Qwen3-Embedding 0.6B、1024 维，本地抽样 100 条：

| 策略 | Hit@10 | NDCG@10 | P95 |
| --- | ---: | ---: | ---: |
| 纯词法 | 1.000 | 1.000 | 28.56 ms |
| 纯向量 | 1.000 | 1.000 | 194.24 ms |
| 词法+向量混合 | 1.000 | 1.000 | 47.28 ms |
| 混合+硬过滤+结构化重排 | 1.000 | 1.000 | 225.68 ms |

`hybridGainObserved=false`。四组并列并不表示模型已经达到真实 100% 准确率，而是当前合成问法和菜名原型区分度不足，无法测出策略差异。该结果只能证明链路可运行、结果受租户和安全规则约束。

500 个全局概念均已生成 1024 维向量。300 条概念评测中有 289 条带 `expectedConceptIds`，Top-3 命中 285 条，命中率 98.62%，P95 为 188.02 ms。4 条未命中已保留在失败报告中。

## 5. 故障覆盖

每类 10 条，共 100 条：

- Embedding 超时

- Chat 503
- SQLite busy
- 菜单过期

- 模型 JSON 非法

- 弱网

当前全部满足预期降级契约。这里验证的是应用层注入，不等同于生产网络、连接池和进程级混沌测试。
